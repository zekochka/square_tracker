# Квадрат

Минималистичный личный трекер полезных действий. Одно действие — один квадрат. Работает без аккаунта и отдельной СУБД.

## Запуск

Нужен Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Сервер слушает только локальный адрес `127.0.0.1`. Для проверки сборки: `npm run build`.

## Устройство проекта

- `src/app` — экраны «Сегодня», «История», «Статистика», стили и PWA-манифест.
- `src/components` — общие элементы интерфейса, формы, список и график.
- `src/features/squares` — состояние квадратов и обновление текущей локальной даты.
- `src/repositories` — интерфейс репозитория и клиентские запросы к API. UI не обращается к файлу напрямую.
- `src/app/api` и `src/server` — API и чтение/запись JSON-файла.
- `src/lib` — работа с локальными датами, группировка и статистика.
- `src/types` — модель записи.

Данные сохраняются в `data/squares.json` на устройстве, где запущен сервер. Файл создаётся автоматически при первой записи; для постоянного хранения серверу нужен доступ на запись в папку `data`. Дата и время создания сохраняются вместе с записью с учётом локального времени браузера. Это удерживает квадрат в исходном дне даже при смене часового пояса. Очистка данных браузера историю не удалит. Приложение рассчитано на личный локальный запуск: если открыть его другим устройством через тот же сервер, оно увидит тот же файл.
